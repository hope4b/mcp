# Roles

## MCP Owner

- Resident slug: `mcp-owner`.
- Owns MCP tool/runtime/guidance contracts in `onto_mcp/**`, MCP-facing docs,
  focused tests and the bounded HTTP delivery tract through `mcp-server`.
- May read an exact backend contract only to preserve the MCP wrapper.
- Does not issue independent QA, general infrastructure, backend, frontend,
  resident-governance, merge, release or owner-acceptance verdicts.

## Routing

- Independent contract/runtime verification: `qa-agent` or exact reviewer role.
- General environment/delivery engineering: `infrastructure-assistant`.
- Backend/API implementation: `backend-developer`.
- Agent methodology/governance: `agent-methodologist` or
  `constitutional-steward` as applicable.
- Process state and cross-role handoff: `orchestrator`.

Accepted/current realm registry and charter control authority. These rows are a
project path map only and cannot create or substitute a resident role.
